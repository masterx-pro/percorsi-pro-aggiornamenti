# Percorsi Pro – aggiornamenti

Questo repository contiene **solo le release** di Percorsi Pro usate
dall'aggiornamento automatico del programma. Il codice sorgente non è qui.

Ogni release contiene:

- `PercorsiPro_v<versione>.zip` – i file del programma;
- `PercorsiPro_v<versione>.zip.sig` – la firma digitale (Ed25519) di versione
  e contenuto.

Il programma installa un aggiornamento solo se la firma è valida per la sua
chiave pubblica: un file modificato, non firmato o di un'altra versione viene
rifiutato.
